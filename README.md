# Black Wolves Website

Statische Website für die Black Wolves Volleyballmannschaft aus Salzburg.

## Dateien

- `index.html` - Seiteninhalt
- `styles.css` - Design in Schwarz/Rot
- `script.js` - mobile Navigation und Jahreszahl

## Hosting-Ziel

Die Seite ist für GitHub Pages vorbereitet. Eine eigene Domain (.at oder .com) wird später verbunden.

## Datenschutz-Startregeln

- Keine Cookies
- Keine externen Fonts
- Keine Tracker
- Keine Social-Media-Embeds
- Social Media nur als normale Links
